# Internet & Web Fundamentals

An educational single-page website covering the core concepts behind the Internet and the modern Web. This project was created as a university assignment and is deployed on Vercel.

## Live Demo

[Open the deployed website](https://assignment-47o3s0eyj-hifzayasmeen79-6806s-projects.vercel.app/)

## Overview

The page presents a structured, easy-to-navigate guide to Internet and web technologies. It includes explanations, examples, diagrams, and responsive layouts for desktop and mobile screens.

## Topics Covered

- The Internet and the World Wide Web
- Web browsers, web servers, and the client-server model
- Websites, web pages, URLs, domain names, DNS, and IP addresses
- Internet protocols, HTTP, and HTTPS
- HTML, CSS, JavaScript, and responsive web design
- Web accessibility and search engines
- Web hosting and cloud computing
- Web security, privacy, and cookies
- Email and hyperlinks

## Features

- Responsive design for desktop, tablet, and mobile devices
- Table of contents with anchor navigation
- Accessible semantic HTML structure and descriptive image alternatives
- Self-contained diagrams embedded directly in the HTML file
- Code examples for each topic
- Clean visual design with no external runtime dependencies

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- SVG diagrams embedded as data URLs

## Run Locally

Because this is a static website, no package installation or build step is required.

1. Clone or download the project.
2. Open `index.html` in a modern web browser.

For a local development server, run one of the following commands from the project directory:

```bash
npx serve .
```

or use the **Live Server** extension in Visual Studio Code.

## Deployment

The project can be deployed to Vercel as a static site:

1. Import the repository into Vercel.
2. Select the project directory.
3. Leave the build command empty.
4. Set the output directory to `.`.
5. Deploy.
