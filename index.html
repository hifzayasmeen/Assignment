These topics explain how information travels across networks and how developers create useful, accessible websites.

1. The Internet

The Internet is a global network of interconnected computer networks that exchange data using common communication standards.

  • It connects billions of devices worldwide.
  • It supports services such as the web, email, streaming, and file transfer.
Device A  -- Internet --  Device B

2. The World Wide Web

The World Wide Web is an information system of linked resources accessed through the Internet using web browsers.

  • Web resources are commonly identified by URLs.
  • Web pages use technologies such as HTML, CSS, and JavaScript.
https://www.university.edu/courses

3. Web Browsers

A web browser is application software that requests, interprets, and displays web resources.

  • Examples include Chrome, Firefox, Edge, and Safari.
  • Browsers render HTML, apply CSS, and execute JavaScript.
Browser: Open URL -> Render page

4. Web Servers

A web server stores website files and delivers them to clients in response to requests.

  • It can serve static files or generate dynamic responses.
  • Common server software includes Apache, Nginx, and IIS.
server.get("/", (request, response) => {
    response.send("Welcome!");
});

5. Client-Server Model

In this model, a client requests a service and a server processes the request and returns a response.

  • The browser acts as the client.
  • The server may access databases, APIs, or application logic.

6. Websites and Web Pages

A website is a collection of related web pages under a common domain. A web page is one document within that collection.

  • Pages may be static or dynamically generated.
  • Navigation connects related pages for visitors.

7. URL

A Uniform Resource Locator identifies the location and access method of a resource on a network.

  • It may contain a scheme, domain, path, query, and fragment.
  • Example: https://www.example.com/about

8. Domain Names

A domain name is a readable address used to identify a website instead of requiring users to remember an IP address.

  • example.com contains a name and a top-level domain.
  • Domains are registered through domain registrars.

9. DNS

The Domain Name System translates human-readable domain names into IP addresses.

  • DNS works like a distributed directory for the Internet.
  • It allows a domain to change servers without changing its public name.

10. IP Address

An Internet Protocol address identifies a device or network interface so data can be delivered to the correct destination.

  • IPv4 uses 32-bit addresses, while IPv6 uses 128-bit addresses.
  • Addresses may be public or private.

11. Protocols

Protocols are agreed rules that define how devices format, transmit, and receive data.

  • They ensure that different hardware and software can communicate.
  • Examples include TCP/IP, HTTP, FTP, and SMTP.

12. HTTP and HTTPS

HTTP transfers web resources between clients and servers. HTTPS adds encryption through TLS.

  • HTTPS protects data from being read or changed in transit.
  • A secure page normally begins with https://.

13. HTML

HyperText Markup Language provides the structure and meaning of web content.

  • Semantic elements describe purpose, such as <header>, <main>, and <footer>.
  • HTML can contain text, images, forms, lists, and links.

14. CSS

Cascading Style Sheets control the visual presentation and layout of HTML documents.

  • CSS manages colors, spacing, typography, and responsive layouts.
  • Rules consist of selectors and declarations.

15. JavaScript

JavaScript is a programming language used to add behavior and interactivity to web pages.

  • It can respond to events and update the Document Object Model.
  • It can communicate with servers using APIs.

16. Responsive Web Design

Responsive design makes a website adapt to different screen sizes, orientations, and input methods.

  • Flexible layouts, relative units, and media queries are commonly used.
  • Content should remain readable on mobile devices.

17. Web Accessibility

Accessibility means designing websites that people with different abilities can use effectively.

  • Use semantic HTML, keyboard-friendly controls, and meaningful alternative text.
  • Provide sufficient color contrast and clear focus states.

18. Search Engines

Search engines discover, index, and rank web pages so users can find relevant information.

  • Crawlers follow links to discover content.
  • Descriptive titles and useful content help search visibility.

19. Web Hosting

Web hosting provides storage, connectivity, and server resources needed to publish a website online.

  • Hosting plans may be shared, virtual private, dedicated, or cloud-based.
  • Important features include uptime, storage, bandwidth, and backups.

20. Cloud Computing

Cloud computing delivers computing resources such as storage, servers, and software over a network on demand.

  • It can scale resources as traffic changes.
  • Users often pay for the resources they consume.

21. Web Security

Web security protects websites, users, and data from unauthorized access and malicious activity.

  • Use strong authentication, secure updates, validation, and HTTPS.
  • Common threats include phishing, malware, injection, and cross-site scripting.

22. Privacy and Cookies

Privacy concerns how websites collect, use, store, and share personal information. Cookies are small data values stored by a browser.

  • Cookies can remember preferences or support analytics and sessions.
  • Websites should explain data practices and request consent where required.

23. Email on the Internet

Email is a digital messaging service that sends information between mail servers and user mail clients.

  • SMTP is used for sending mail, while IMAP and POP3 support receiving it.
  • Attachments allow files to be shared with a message.

24. Hyperlinks / Links

A hyperlink connects one resource to another and is activated by selecting linked text, an image, or another element.

  • The HTML <a> element creates links.
  • Links may point to another page, a section on the same page, an email address, or a downloadable file.

Example: <a href="#the-internet">Return to The Internet</a>
